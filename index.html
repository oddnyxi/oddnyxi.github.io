About

Hi, I'm Nyxi.

Also known as Nyxi Kitty. I build things that talk over the wire, take apart things that weren't meant to be opened, and keep servers and databases standing when people pile onto them. What I'm best at is networking, especially multiplayer networking.

I also make music. Beats and tracks go on SoundCloud, videos on YouTube and code on GitHub. When I'm away from the computer, I'm out urban exploring: abandoned buildings, rooftops, tunnels and the forgotten corners of the city.

Lately I've been taking Unity WebGL games apart from the inside. Odium UE explores a running IL2CPP game in the browser, and BananaLoader turns that into a full mod loader with JavaScript mods.

Right now I'm building FloofVR, a multiplayer social VR game in Godot 4 with a Bun and TypeScript server, by myself.

Projects

MeowEngine

FishNet 4.x protocol SDK · userscript
GitHub

A Bullet Force mod base built around a from-source implementation of the FishNet 4.x wire protocol, running over Bayou's WebGL WebSocket transport, with an Odium UI menu on top.

  • Decodes and re-encodes every FishNet packet, checked release by release from 4.4.3 to 4.7.x
  • Lossless pass-through: only edited packets are re-serialised
  • Live mirror of objects, owners, RpcLinks and ping, plus hooks in both directions
  • Packet inspector, RPC explorer and composer
JavaScriptFishNetWebSocketsReverse engineering

BananaLoader

MelonLoader for Unity WebGL · JavaScript
GitHub

A MelonLoader-style mod loader for Unity WebGL games compiled with IL2CPP. Mods are JavaScript files called Banans. They get MelonLoader's lifecycle, Harmony-style patches and game objects that act like C#, all inside the browser tab.

  • Prefix and postfix patches on any method, including direct calls: the game's wasm is rewritten at load time
  • Generic types and methods: List<int>, GetComponent<T>(), patched per instantiation
  • Dependencies with version ranges, hot reload, preferences and coroutines
  • Exports a .d.ts of the whole game for typed autocomplete in VS Code
JavaScriptWebAssemblyIL2CPPModding

Odium UE

Unity Explorer for WebGL IL2CPP games · userscript
GitHub

A runtime explorer for Unity WebGL games. It reads the IL2CPP metadata straight from the game's memory and gives you the scene tree, an inspector and a class browser, with no build-specific offsets.

  • Scene hierarchy, live field and property editing, and method calls with ref and out
  • Click an object in the game to select it, through UI hits and camera raycasts
  • Class browser over every assembly, with live instance search
  • Works from Unity 2021.2 to Unity 6 (metadata v29 and v31)
JavaScriptWebAssemblyIL2CPPReverse engineering
